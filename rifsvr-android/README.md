# RiFSVR Android Test 0.1.0

Experimental standalone Android ARM64 frontend for musicastudio/FSVR. This branch is separate from RiGear/Osirus and uses package `com.rinoize.rifsvr`.

The complete authored Android project is in `project.tar.xz` (SHA256 `19a47985ae4491a3eeba2d37c45af38ca4b332a42238f2a645bef14eb590403f`). Extract it into a new directory with `tar -xJf project.tar.xz`. GitHub Actions builds its native engine self-tests first, then the Android APK; the artifact includes the expanded corresponding source, build report and Spanish instructions. No build success or physical-tablet performance is implied by this source commit.

Upstream is pinned to musicastudio/FSVR commit `d6aad1e56454a307fd952d8d4dfce05bea7eda84`. The wrapper uses GPL-3.0-only, and preserves upstream LICENSE and NOTICE. The upstream NOTICE explicitly distinguishes GPL code from Yamaha-origin conversion tables, algorithms and preset data, which are not ours to license.

Prototype scope: 48 kHz stereo AudioTrack/JNI, 384 factory performances, 1408 voices in isolated single-part mode, linked factory FSeq loading, USB MIDI input, touchscreen keyboard, gain/modulation/bend/sustain, panic, 256/512/1024-frame processing blocks, DSP deadline and AudioTrack underrun counters, foreground-only audio, landscape and screen-on while visible. Full editing, MIDI SysEx import/output, incoming Program Change selection and manual FSeq selection are not implemented in this prototype.

A deliberately non-production test signing key is generated by the build and included in its source artifact to support further test updates. Do not use this key for production or sensitive apps. See the extracted LEEME.txt.
